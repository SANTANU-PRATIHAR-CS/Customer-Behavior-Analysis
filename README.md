# 📊 Customer Behavior Dashboard | Data Analysis Project

An interactive Customer Behavior Analysis Dashboard built using Python, SQL, and Power BI to analyze customer purchasing patterns, subscription behavior, revenue trends, sales performance, and demographic insights.

## 🚀 Tools & Technologies Used

* Python – Data Cleaning & Preprocessing
* SQL – Data Extraction & Business Queries
* Power BI – Interactive Dashboard & Visualization
* Excel – Initial Data Handling & Formatting

## 📌 Key Insights

* Customer subscription analysis
* Revenue & sales by product category
* Age-group purchasing behavior
* Shipping preference trends
* Customer review & purchase analysis

## 📈 Dashboard Features

* Interactive filters & slicers
* KPI cards for quick business insights
* Category-wise sales & revenue analysis
* Customer demographic visualization
* Dynamic and user-friendly dashboard design

## 🎯 Project Goal

This project helps businesses understand customer behavior and make data-driven decisions through powerful visual analytics.
